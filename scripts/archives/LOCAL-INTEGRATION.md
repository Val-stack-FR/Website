## Closed joins and catalogue scope

`reader-allowlist.mjs` joins existing reader endpoints to the verified media
allowlist by object ID, view ID, SHA-256 and accepted review ID. The coverage
adapter independently requires that same review evidence. Names and folders
cannot create a reader link. The preview server rechecks those links against
the reader export and rendered dossier anchors.

The adapter validates every input row and checksum before projecting image
occurrences. The CLI defaults to `--collection-scope clean`; `all` is an
explicit inspection option for the standalone adapter, and the integrated
server refuses any non-CLEAN record. This image projection excludes nonimage
inventory entries. Inventory files, candidate groups and dossiers are not
counts of identified historical acts.

The catalogue has fifty static initial cards and a bounded same-origin data
route for search, filters and pagination. It does not ship the entire input
package to the browser. Unknown parameters, duplicate parameters and invalid
pagination are refused. No raw input file is a public route.

## Preparation and launch

Use explicitly authorized local derivative paths; do not put a corpus locator
in source control. A fresh preflight bound to the exact source manifest is
required before opening selected originals. Preparation can be repeated only
into a new output directory.

```powershell
node scripts/archives/prepare-local.mjs `
  --coverage-directory <verified-coverage-directory> `
  --reader <reader-export.json> `
  --media-manifest <verified-media-allowlist.json> `
  --source-manifest <source-input-manifest.json> `
  --preflight <passed-manifest-bound-preflight.json> `
  --annex <approved-five-fiche-query-index.json> `
  --output .private/archives-mvp/<new-run> `
  --generated-at <explicit-ISO-timestamp> `
  --corrections-origin http://127.0.0.1:<owned-port> `
  --correction-text-id <explicit-supported-reader-text-id>

# PHD_CORPUS_ROOT is configured only in this process after the preflight.
node scripts/archives/preview-server.mjs `
  --html .private/archives-mvp/<new-run>/reader.html `
  --catalogue .private/archives-mvp/<new-run>/catalogue.json `
  --reader-export <reader-export.json> `
  --search-html .private/archives-mvp/<new-run>/search.html `
  --status-html .private/archives-mvp/<new-run>/status.html `
  --media-manifest <verified-media-allowlist.json> `
  --source-manifest <source-input-manifest.json> `
  --preflight <passed-manifest-bound-preflight.json> `
  --port <owned-unused-port>
```

An existing authorized occurrence page can be supplied with
`--occurrence-html`. It remains a candidate context window, not a validated
word alignment. Invalid image orientation metadata is a separate unresolved
gate.

Correction links are navigation to a separate private service, only for
explicitly supported text IDs already present in the reader. This preview
does not open cross-origin API access. Local owner sessions and simulated
decisions do not establish the owner's human identity or validate historical
readings. The correction service has its own session, persistence and reader
binding contracts.
