# Read-only archive publication adapter

`createReadonlyHandler({ catalogue, index, lexical, hierarchy?, transformHtml?, render? })` binds the already prepared catalogue model, preexisting-text index and lexical index to a Node/Vercel request handler. It performs no file reads or writes. Build and validate those objects at deployment startup from explicitly selected packages, then export `handler` from the Vercel route. `createVercelRoute(data)` is the small route factory.

The adapter preserves `GET` and `HEAD` on `/__catalogue_data`, `/__catalogue_hierarchy`, `/archives/catalogue/`, `/archives/textes/`, `/archives/texte/?object_id=…` and `/archives/reperes/`. HTML uses the accepted canonical renderers. `transformHtml(html, url)` lets the site add its Atelier navigation. `/archives/catalogue/` defaults to the canonical CLEAN hierarchy, including query URLs without an explicit folder; `/__catalogue_data` remains the flat catalogue API. Hierarchy responses preserve the global inventory, CLEAN and authorized-reader-link counts used by the existing preview. Optional `folderNotes` are an explicitly supplied array of `{ folderPath, text, object_ids }`; the default is `null`. All dynamic endpoints reject duplicate, unknown, overlong and unsupported parameters. Other methods return 405; unlisted paths return 404.

The request-time dependency list and transitive import edges are in `dependencies.json`, including built-ins used by `preexisting-texts.mjs` and `lexical-search.mjs`. No package installation is needed. The handler exposes no filesystem path or secret and retains the private, unknown-rights and unreviewed states encoded in the prepared indexes.
